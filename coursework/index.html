Coursework Archive

Reports, papers, screenshots, and public coursework organized like a library instead of a dump.

This archive is built from the local coursework tree and organized by semester and course. Public documents are hosted directly on the site, while code-heavy projects are meant to link out to GitHub as they are cleaned up and published.

Publication Rules

Documents live here. Source code gets linked out. Private material stays out.

  • Reports, papers, research briefs, screenshots, and course writeups are hosted directly on the site.
  • Code projects are cataloged here, but the public destination should be GitHub rather than raw source copies.
  • Original `.docx` files stay as source where needed, but PDF and browser-friendly formats are preferred.
  • Textbooks, syllabi, instructor materials, private keys, tokens, passwords, and bulky lab dumps are excluded.
